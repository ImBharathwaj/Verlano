# Verlano UI Design System

This document defines the visual design system for the Verlano ecommerce platform.

Goal: Create a **premium luxury aesthetic** that reflects the Verlano brand.

Design principles:

- Minimal
- Elegant
- Clean
- Spacious
- Premium

---

# Brand Identity

Brand Name

Verlano

Brand Positioning

Premium fashion at accessible prices.

Brand Message

Luxury within reach.

---

# Color System

Luxury brands typically use a minimal palette.

Primary Colors

Black  
#0F0F0F

Ivory / Cream  
#F5F3EF

Gold Accent  
#C6A75E

Secondary Colors

Soft Gray  
#E5E5E5

Dark Gray  
#4A4A4A

Usage

Black → backgrounds  
Ivory → main page background  
Gold → accent highlights

Avoid bright colors.

---

# Typography

Luxury brands use **elegant serif fonts for headlines** and **clean sans-serif fonts for body text**.

Heading Font

Playfair Display

Used for:

- Hero titles
- Section headings
- Product titles

Body Font

Inter

Used for:

- Descriptions
- Navigation
- UI elements

Example

Heading

VERLANO COLLECTION

Body

Premium surplus clothing curated for modern style.
